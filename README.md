## sobre

Não uso PC. Tudo aqui — scripts, sites, o que for — sai do Termux, no
celular, sem servidor por trás quando dá pra evitar. Prefiro um arquivo
único que roda de cara a uma stack de dez peças pra fazer a mesma coisa.

Foco: automação, ferramentas de terminal, e uns projetos web soltos em
HTML/CSS/JS puro.
